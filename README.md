# NEON VECTORS

竖屏几何弹幕射击游戏。纯 Canvas 2D 绘制，零运行时依赖。

## 玩法

- **标准**：3 点护盾，受击后 1.2 秒无敌，适合先熟悉弹幕节奏。
- **硬核**：一命通关，敌人更多、弹幕更快。
- 开局流程：标题选难度 → 选武器 → 进入战斗。
- 自动射击，杀敌得分，每 20 秒提升一波难度。
- 三种敌机：六边形核心（瞄准弹）、尖刺突进（扇形散弹）、炮台（旋转弹环）。
- 炸弹：每局 3 枚，清空敌弹并短暂无敌；`Esc` 暂停。
- 连击：连续击杀提升倍率（最高 ×8，近身击杀再 +1），吃能量核心延长连击窗口。
- 武器：开局三选一，拾取模块升到 5 级。
  - `PULSE` 均衡扇射，容错最高。
  - `LANCE` 精准穿透，单发高伤，适合跟枪打 Boss。
  - `SCATTER` 近距爆发，宽扇多弹，远距离乏力。
- Boss：每 60 秒一场，三种形态（HEX / ORBIT / PRISM）每 3 场循环，各三阶段专属弹幕；阶段切换 1 秒无敌、缓动换位、敌弹被护盾吸收。
- 音效与 BGM：全部由 WebAudio 实时合成，无音频文件；`M` 一键静音。
- 表现力：命中定格、Boss 击杀慢动作、开火预警圈、HUD 与标题动效。

## 操作

| 动作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 按住拖动 |
| 选择难度 / 武器 | `←` `→` / `A` `D` · 空格 / 点击 | 点击卡片 |
| 开始 / 重开 | `空格` / `Enter` / `R` | 点击 |
| 暂停 | `Esc` / `P` | 右上角暂停按钮 |
| 炸弹 | `X` / `Shift` | 右下角炸弹区 |
| 设置 | `S` | 点击右上角「设置」 |
| 返回标题 | `Esc` | 点击「返回」 |
| 静音 | `M` | — |

## 设置

标题页按 `S` 或点击右上角「设置」进入，全部配置保存在本地：

- 主音量 0–100%
- 音效 / BGM 独立开关
- 震动开关（移动端）
- 画质高 / 低（低画质减少粒子与背景星点）
- 恢复默认

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产出 dist/
```

## 部署

推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。Vite 使用相对路径 `base: './'`，可直接部署到任意子目录。

在线试玩：`https://15876167663.github.io/NEON-VECTORS/`

## 目录结构

```
src/
  main.js            启动、画布适配、固定步长循环
  config.js          数值、配色、难度定义
  input.js           键盘与指针输入
  audio.js           WebAudio 音效与合成 BGM
  core/draw.js       绘制工具
  game/Game.js       场景调度
  game/director.js   出怪导演与波次
  game/weapons.js    武器弹道
  entities/          玩家、敌人、子弹、粒子
  render/            背景与 HUD
  settings.js        本地设置与震动
  scenes/            标题、设置、战斗
```
